# SOP: Weekly SEO Review, Keyword Research, GA4 Analysis & SEO Implementation

**For Client Websites + RAAS Websites**
**Tools:** Ubersuggest, Google Analytics 4, Client Dashboard, SEO Master Tracker
**Version:** 1.0

Ubersuggest will be used for rank tracking, keyword research, technical site audits, SEO opportunities, and competitor visibility. 

GA4 will be used to track web traffic, acquisition, organic search behavior, landing-page performance, engagement, and key events/conversions. 

---

# 1. Purpose

The purpose of this SOP is to create a repeatable weekly SEO workflow across all active websites.

This process ensures the team continuously:

1. Reviews SEO performance.
2. Reviews GA4 traffic and engagement.
3. Expands the list of keywords being tracked.
4. Identifies ranking, content, and technical opportunities.
5. Implements SEO improvements across every site weekly.
6. Keeps the client dashboard updated.
7. Assigns execution clearly to the correct dev team member.
8. Builds long-term organic traffic, leads, sales, and visibility.

The core rule:

**Every site gets reviewed weekly. Every site gets an SEO action or a documented reason for no action.**

# 7. Weekly Review Workflow

## Step 1: Open Ubersuggest Project

For each site:

1. Open the correct Ubersuggest project.
2. Confirm the correct domain.
3. Confirm location settings.
4. Confirm device settings if applicable.
5. Review rank tracking.
6. Review keyword movement.
7. Review site audit.
8. Review SEO opportunities.
9. Review competitor visibility.
10. Record findings in the SEO Master Tracker.

---

## Step 2: Open GA4 Property

For each site:

1. Open the correct GA4 property.
2. Go to **Reports**.
3. Review **Acquisition**.
4. Review **Traffic Acquisition**.
5. Filter or review **Organic Search**.
6. Review **Landing Pages**.
7. Review engagement metrics.
8. Review key events or conversions.
9. Record findings in the SEO Master Tracker.

---

## Step 3: Compare Ubersuggest + GA4

Use both tools together.

| Ubersuggest Shows  | GA4 Shows                 | Meaning                                                      |
| ------------------ | ------------------------- | ------------------------------------------------------------ |
| Rankings improving | Organic traffic improving | SEO is likely gaining traction                               |
| Rankings improving | Traffic flat              | Keyword may have low traffic, weak CTR, or SERP issue        |
| Rankings flat      | Traffic improving         | Traffic may be coming from other sources or long-tail search |
| Rankings dropping  | Traffic dropping          | Investigate technical, content, or competitive issue         |
| Traffic improving  | Engagement weak           | Page may not satisfy user intent                             |
| Traffic strong     | Conversions weak          | CTA, offer, trust, or funnel problem                         |

# 10. Keyword Research SOP

## 10.1 Weekly Keyword Expansion Targets

| Website Type    | Keyword Candidates Per Site | Approved Keywords Added to Tracking |
| --------------- | --------------------------: | ----------------------------------: |
| Client websites |                 5–15 weekly |                         3–10 weekly |
| RAAS websites   |                10–25 weekly |                         5–15 weekly |

---

## 10.2 Keyword Research Sources

Use Ubersuggest to find:

1. Keyword ideas.
2. Related keywords.
3. Question keywords.
4. Comparison keywords.
5. Preposition keywords.
6. Competitor keywords.
7. Top-ranking competitor pages.
8. Existing ranking keywords not yet tracked.
9. SEO opportunities.
10. Long-tail terms.
11. Product/service-specific keyword variations.
12. GA4 landing-page insights.

---

## 10.3 Keyword Qualification Score

Each keyword must be scored before being added to tracking.

| Factor                    |              Score |
| ------------------------- | -----------------: |
| Search intent fit         |                1–5 |
| Revenue or lead potential |                1–5 |
| Ranking feasibility       |                1–5 |
| Search volume             |                1–5 |
| Page fit                  |                1–5 |
| Competition difficulty    | 1–5, subtract this |

Formula:

```text
Keyword Priority Score =
Search Intent Fit
+ Revenue / Lead Potential
+ Ranking Feasibility
+ Search Volume
+ Page Fit
- Competition Difficulty
```

---

## 10.4 Keyword Approval Rules

A keyword may be approved only if:

1. It matches the site’s offer.
2. It has clear search intent.
3. It maps to an existing or planned page.
4. It has realistic ranking potential.
5. It supports traffic, leads, sales, visibility, or authority.
6. It is not only a vanity keyword.

---

# 11. Keyword Mapping SOP

Every approved keyword must be mapped before implementation.

| Field                   | Requirement                                                     |
| ----------------------- | --------------------------------------------------------------- |
| Website                 | Site name                                                       |
| Assigned Dev            | Dev owner                                                       |
| Primary Keyword         | One main keyword per target page                                |
| Secondary Keywords      | 3–10 supporting keywords                                        |
| Search Intent           | Transactional, commercial, informational, navigational, local   |
| Funnel Stage            | Awareness, consideration, purchase, retention                   |
| Target URL              | Existing or planned URL                                         |
| Page Type               | Homepage, product, collection, service, blog, landing page, FAQ |
| Current Ranking         | From Ubersuggest                                                |
| Current Organic Traffic | From GA4                                                        |
| Status                  | Researching, approved, implemented, tracking, needs revision    |
| Next Review Date        | Follow-up date                                                  |

---

## Cannibalization Rule

Do not assign the same primary keyword to multiple pages unless the SEO Lead approves a hub-and-spoke structure.

# 13. On-Page SEO Implementation SOP

## Step 1: Review the Target Page

The assigned dev and SEO specialist review:

1. Page title.
2. Meta description.
3. H1.
4. H2/H3 structure.
5. Body copy.
6. Product/category/service description.
7. Image filenames.
8. Image alt text.
9. Internal links.
10. CTA placement.
11. FAQ section.
12. Schema, if applicable.
13. URL slug.
14. Mobile layout.
15. Page speed concerns.
16. Indexability.

---

## Step 2: Implement SEO Updates

| Element              | Standard                                                     |
| -------------------- | ------------------------------------------------------------ |
| Title Tag            | Include primary keyword naturally, preferably near the front |
| Meta Description     | Include keyword, benefit, and CTA                            |
| H1                   | One clear page-level H1                                      |
| H2/H3                | Use supporting keywords naturally                            |
| Body Copy            | Match user intent and provide useful information             |
| Product/Service Copy | Add benefits, features, use cases, and objections answered   |
| Internal Links       | Add 2–5 relevant internal links                              |
| Image Alt Text       | Descriptive and natural, not spammy                          |
| FAQ                  | Add 3–5 useful questions when appropriate                    |
| CTA                  | Match page intent                                            |
| URL Slug             | Clean, readable, keyword-aligned where possible              |
| Schema               | Add or improve when applicable                               |

---

## Step 3: QA After Implementation

The assigned dev must confirm:

1. Page is live.
2. Page loads correctly.
3. Formatting is clean.
4. Links work.
5. Images load.
6. Metadata is updated.
7. Mobile layout is clean.
8. CTA works.
9. Tracking remains active.
10. Page is logged in the SEO Master Tracker.
11. Dashboard note is updated if client-facing.

# 15. GA4 Analysis SOP

## 15.1 Weekly GA4 Review

For every site, review:

1. Organic Search traffic.
2. Organic users.
3. Organic sessions.
4. New users from Organic Search.
5. Engaged sessions.
6. Engagement rate.
7. Average engagement time.
8. Top organic landing pages.
9. Key events.
10. Conversions.
11. Revenue, if ecommerce.
12. Form submissions or inquiries, if lead-gen.

---

## 15.2 GA4 Red Flags

Flag a site if:

1. Organic traffic drops more than 20% week over week.
2. Organic traffic rises but engagement drops.
3. A ranking page gets traffic but no key events.
4. A money page gets little or no organic traffic.
5. Engagement rate is weak on organic landing pages.
6. Conversions are flat despite traffic growth.
7. Traffic spike appears unrelated to SEO.
8. Top landing pages do not align with business goals.

---

## 15.3 GA4 + SEO Decision Rules

| Scenario                                     | Action                                                    |
| -------------------------------------------- | --------------------------------------------------------- |
| Rankings up + traffic up + engagement strong | Protect page, add internal links, expand related keywords |
| Rankings up + traffic up + engagement weak   | Improve intro, content match, CTA, trust signals, layout  |
| Rankings up + traffic flat                   | Improve title/meta, check volume, review SERP features    |
| Traffic up + rankings flat                   | Check other channels, long-tail queries, referrals        |
| Rankings down + traffic down                 | Check technical issues, content freshness, competitors    |
| Traffic strong + conversions weak            | Improve offer, CTA, trust proof, funnel path              |
| Traffic weak + keyword opportunity strong    | Create or optimize dedicated page                         |
| Page gets impressions but poor action        | Improve copy, speed, UX, CTA, and internal linking        |

# 23. Priority Scoring System

Use this to decide what gets done first.

| Priority | Meaning                                                       | Action                                |
| -------- | ------------------------------------------------------------- | ------------------------------------- |
| P0       | Site-breaking, crawl, indexing, tracking, or conversion issue | Fix immediately                       |
| P1       | Keyword ranking positions 4–20 with commercial intent         | Optimize this week                    |
| P2       | Money page under-optimized                                    | Improve title, meta, copy, CTA, links |
| P3       | Strong keyword with no matching page                          | Create content brief                  |
| P4       | Technical warning or minor SEO improvement                    | Add to backlog                        |
| P5       | Low-value vanity keyword                                      | Ignore or revisit later               |

# 24. Quality Standards

## SEO Copy Must Be

1. Clear.
2. Useful.
3. Human-readable.
4. Search-intent aligned.
5. Benefit-driven.
6. Naturally keyword-optimized.
7. Free of keyword stuffing.
8. Matched to the page’s business goal.

## SEO Copy Must Not Be

1. Robotic.
2. Generic.
3. Overstuffed with keywords.
4. Misleading.
5. Claim-heavy without support.
6. Thin or useless.
7. Written only for Google.
